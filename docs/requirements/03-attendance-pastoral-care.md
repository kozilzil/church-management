# 출석과 목양 요구사항

## Attendance

`Gathering`은 주일예배, 수요예배, 구역모임, 교육과 같은 출석 대상 모임이다.
반복 일정 정의와 실제 회차(`GatheringSession`)를 분리한다.

- 출석 상태 예시: PRESENT, ABSENT, LATE, EXCUSED, UNKNOWN
- QR, 수기, 일괄 업로드 등 입력 출처를 기록한다.
- 동일 Member와 회차의 출석은 하나만 활성화한다.
- 수정 전후 값과 수정자를 감사할 수 있어야 한다.

## Pastoral care

심방과 상담에는 매우 민감한 정보가 포함될 수 있다. 기본 메타데이터와 제한 메모를
분리하고, 일반 교적 조회 권한만으로 상세 메모를 볼 수 없게 한다.

- 방문/연락 일시, 유형, 담당자, 대상 Member/Household
- 공개 범위: 담당자 전용, 지정 그룹, 목회자, 관리자
- 후속 조치와 예정일
- 첨부파일은 별도 저장소와 접근 만료 URL 사용

## 보존 원칙

민감 메모의 보존기간과 파기 정책은 실제 교회 정책이 정해진 후 구현한다. 정책 확정
전에는 상세 상담 기록 기능을 운영 배포하지 않는다.
