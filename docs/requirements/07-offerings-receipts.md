# 개별 헌금과 기부금영수증

## 확정 목표

배치 없이 헌금 한 건을 등록·수정·검수·회계 게시한다. 교인 연결 기명, 교적에 없는 개인 기명,
익명 금전 헌금을 지원한다. 기부금영수증은 실제 기부자별·귀속연도별 확정 헌금에서 발급한다.

- 헌금 종류는 수익 계정·기금·영수증 대상 여부를 가진다. 입금 자산 계정은 건별 지정한다.
- DRAFT → REVIEWED → POSTED. 입력/최종 수정자와 검수자는 다르다. 검수 후 수정하면 DRAFT로 돌아간다.
- POSTED와 CANCELLED는 불변. 게시·역분개는 열린 회계기간에서만 가능하며 회계와 원자적으로 처리한다.
- 교회별 접수 참조는 고유하다. 동시 확정/발급은 교회 쓰기 잠금과 DB 제약으로 중복을 막는다.
- 게시한 헌금은 연결된 역분개로 정정한다. 유효 영수증에 포함되었다면 영수증을 먼저 취소한다.
- 기명 헌금의 기부자와 영수증 기부자는 동일하다. 익명/미확정/취소/역분개/비대상 헌금은 발급 불가.
- 영수증 미리보기에서 선택한 최대 500건을 발급하며, 새 헌금이 추가돼도 미리보기 대상이 바뀌지 않는다.
- 발급번호는 교회·발급연도별 연속 번호. 원본 내용과 항목은 불변이며 재출력은 같은 번호를 사용한다.
- 취소는 사유/담당자/시각을 별도 보존한다. 취소 영수증의 원본 및 항목은 삭제하지 않는다.
- 발급·인쇄 자료 조회·취소에 별도 권한과 감사 이벤트를 적용한다. 운영 발급/취소/게시 담당자는 MFA와 최근 인증을 요구한다.

## 발급 문서와 개인정보

교회 자체 종이 영수증(브라우저 인쇄 및 PDF 저장)을 제공한다. 국세청 홈택스 전자발급/자동 제출은
별도 서비스이며 자체 PDF를 전자기부금영수증으로 표시하지 않는다. 발급기관 설정에 교회명, 고유번호,
소재지, 대표자, 적격 근거 및 확인 기록을 입력한다. 전자발급 의무 대상 여부를 설정하며 해당하는 경우
자체 신규 발급을 차단하고 홈택스에서 처리하도록 안내한다.

소득세법 시행규칙 별지 제45호의2(2025.6.30 개정)의 기부자·단체·모집처·기부내용·서명란을
기준으로 개인의 직접 금전기부(종교단체 코드 41) 문서를 구성한다. 현물 및 법인 기부자 발급은 범위 밖이다.
서명/날인은 인쇄 후 담당자가 수행한다. 수집한 사실과 발급 자격은 교회 담당자가 확인한다.

AGENTS.md의 주민등록번호 전체 저장 금지 원칙을 유지한다. 식별번호는 인쇄 직전에 브라우저에서만
입력하며 API·DB·로그·웹 저장소로 보내지 않는다. 재출력 시 다시 입력한다. 발급명세 원본의 법정 보관은
교회가 서명/날인한 출력본 또는 별도 승인된 보관 체계로 수행한다. 앱의 발급대장은 전체 식별번호를
보유하는 법정 보관 원본을 대체하지 않는다. 기부자 주소와 이름은 발급 시점 스냅샷으로 보존한다.
