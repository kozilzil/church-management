# 홈택스 전자기부금영수증 파일 연동

확정 헌금의 기부자·연도별 미리보기에서 최대 500건을 선택해 홈택스 일괄발급 전산매체
파일을 만든다. 공식 공개 자동 발급 API 명세는 확인되지 않아 로그인·제출은 담당자가 홈택스에서
수행한다. 앱은 자동 전송 또는 국세청 조회 검증을 했다고 표시하지 않는다.

## 제출과 결과

- 국세청 2024.2 전산매체 규격 A0420의 B(170바이트)/D(225바이트), 파이프 구분,
  CRLF, KSC-5601 인코딩을 사용한다. 신규(01), 개인 금전기부(1), 종교단체(41/405)만 지원한다.
- 자료관리번호는 제출 항목 UUID의 하이픈 제거 값이다. 같은 준비 건 재다운로드 시 번호를 유지한다.
- 발급기관 자격·홈택스 발급권한은 담당자가 확인한다. 발급기관 정보와 기부자·헌금 내역은 준비 시점에 고정한다.
- 준비는 발급 완료가 아니다. 준비 즉시 헌금에 claim을 걸어 다른 자체 영수증/홈택스 준비 및 역분개를 막는다.
- 각 항목은 결과 미확인 → 발급 확인 또는 미발급 확인으로 기록한다. 발급 확인에는 홈택스 확인 참조를 요구한다.
  이미 발급한 항목은 홈택스 취소 확인 후에만 취소로 기록한다. 일부 발급과 일부 오류를 함께 관리한다.
- 결과는 담당자의 수동 대조 기록이다. 수정·삭제 대신 이력을 추가한다. 미발급/취소 확인만 claim을 해제한다.
- 다운로드 실패/결과 미확인 시 자동으로 claim을 해제하지 않는다. 재다운로드는 확인된 결과가 전혀 없는 준비 건만 가능하며
  홈택스에 미제출 또는 기존 업로드 삭제 확인을 요구한다. 홈택스 자체 중복검증을 가정하지 않는다.
- 원본 파일 업로드/결과 엑셀 가져오기, 수정·삭제 전산매체, 자동 로그인/인증서 보관은 이번 범위에 포함하지 않는다.

## 개인정보와 권한

주민등록번호는 다운로드 직전 브라우저에서 일회성 입력한다. API/DB/로그/localStorage에 보내거나
저장하지 않는다. 내려받은 파일에는 제출용 식별번호가 들어 있으므로 담당자가 안전하게 보관·폐기한다.
등록번호 자릿수/생년월일은 로컬에서 확인하고 실제 신원 일치 여부는 홈택스 검증 결과를 따른다.
receipt.read 조회 + receipt.export 준비/다운로드 + receipt.reconcile 결과 등록, 운영 MFA/최근 인증 및 감사 기록을 적용한다.

## 완료 기준

규격의 정확한 바이트 길이/코드/합계/날짜/인코딩/구분자와 지원 불가 문자를 검사한다. 실제 DB에서
교회 경계, 권한, 동시 준비, 자체 발급과 중복, 부분 결과, 재다운로드 제한, 취소/재준비, 역분개 차단을 검증한다.
홈택스 실계정 제출은 교회의 발급권한과 실제 자료가 필요하므로 합성 데이터 테스트와 분리해 명시한다.
