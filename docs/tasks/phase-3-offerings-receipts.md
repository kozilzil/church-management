정책: requirements/07-offerings-receipts.md, ADR-008.
법정 원본 보관과 서명/날인은 교회 운영 절차다. 홈택스 전자발급 연동은 포함하지 않는다.
입력자와 검수자를 분리하며 기존 관리자에 개인별 헌금 열람 권한을 자동 부여하지 않는다.
다음 개발 후보는 예산 통제, 재정 보고서, 분할 지급/반환금, 대량 입력/전자발급 연동이다.

## 검증

API 단위 21개, 웹 10개, PostgreSQL 통합 30개(신규 헌금/영수증 7개)를 통과했다.
린트·타입 검사·프로덕션 빌드·migration 실패 gate를 확인했다.
가상 데이터 25건은 A4 3페이지, 최대 길이 이름/주소/근거법령은 A4 1페이지로 출력하고
각 PDF 페이지를 이미지로 렌더링하여 확인했다. 운영 CSP가 적용된 Chrome에서 CSS 로드와 출력 오류가 없음을 확인했다.
