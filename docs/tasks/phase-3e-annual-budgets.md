# Phase 3E: 연간 예산·집행률

## 완료 조건

- [x] 교회·연도·지출 계정·기금별 연간 예산 편성 및 변경 사유.
- [x] 기존 금액 덮어쓰기 없이 변경 이력, 버전 충돌, DB 변경/삭제 차단.
- [x] 실제 게시 원장과 대조한 순지출·잔여액·집행률.
- [x] 예산 초과·미편성·0원 예산·연도를 넘긴 역분개 처리.
- [x] 조회/편성 권한·교회 경계·최근 인증·MFA·CSRF·감사.
