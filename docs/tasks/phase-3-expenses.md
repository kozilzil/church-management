## 구현 결과

FIN-001, EXP-001/002/003/004, ACC-001의 API·관리 화면·migration을 구현했다.
결재선은 요청자가 개인별로 선택하고 위/아래 버튼으로 순서를 조정한다.
수정 후 저장하지 않은 내용은 상신할 수 없고, 저장된 금액·결재선·증빙 확인 후 제출한다.
JPEG/PNG/PDF 첨부, 사진 미리보기, 원본 다운로드 및 이전 회차의 증빙 열람을 제공한다.
지급 시 비용 차변/자산 대변을 자동 생성하며 마감과 역분개를 제공한다.

권한 구성 및 사용 전 설정은 deploy/README.md의 Phase 3A 절차를 따른다.
통합 검증에는 요청자 지정 순서, 반려 후 새 회차, 파일 위장/크기/CSRF/범위,
동시 지급, DB 차변·대변 균형 제약, 원장/증빙 이력 불변성, 마감 및 MFA를 포함한다.
