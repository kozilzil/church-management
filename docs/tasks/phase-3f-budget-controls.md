# Phase 3F: 예산 승인과 지출 예산 통제

## 완료 기준

- 예산 편성/변경 요청, 독립 승인·반려·본인 취소, 승인 후 원자 반영과 불변 이력.
- 지출 연도 필수 입력, 상신 시 예약, 반려·취소 해제와 지급 원장 전환.
- 교회별 WARN/BLOCK 정책, 상신·순차 승인·지급 시 현재 예산 재검사.
- 기존 자료를 추정 변경하지 않는 이행과 미정리 기존 건의 BLOCK 전환 차단.
- 권한·교회·최근 인증·MFA·CSRF·동시성·금액 경계·기존 기능 회귀 검증.
- 웹 승인/통제 설정/예산 상태/확인 이력, PC·모바일 검증.
- 표준 배포, 불변 테이블 runtime 권한, 승인/정책 포함 백업·복구 검증.

정책은 [ADR-012](../decisions/ADR-012-budget-approval-controls.md)를 따른다.

## 검증 결과

- API 단위 24개, 웹 28개, PostgreSQL 통합 60개 시나리오.
- 미승인 금액 미반영·자기 승인 차단·동시 승인 단일 반영·동시 상신 한도 보장.
- 반려/취소 예약 해제, 정확한 한도 지급, 중복 지급 차단, 연도 불일치·미편성·0원.
- 감액 후 승인/지급 재검사, 경고 이력, 기존 연도 미지정 건의 차단 모드 전환 거부.
- 승인 이력 마이크로초 시각 경계 페이지, 교회·권한·CSRF·최근 인증·MFA·불변 DB 이력.
- lint/typecheck/build, 실제 tsx/OpenAPI 기동, migration 및 배포 실패 gate.
- Chrome 데스크톱·390px 모바일: 자기 승인 숨김, 승인 후 반영, 이력, 가로 넘침 없음.
- 표준 Docker 배포·재배포·백업 복구와 새 불변 테이블 권한은 CI 배포 job에서 검증한다.
