홈택스 실제 제출은 교회의 발급권한이 있는 담당자가 수행한다. 자동 전송 API, 결과 엑셀 가져오기,
법인/현물/익명 전자 발급, 수정/삭제 파일 자동 생성은 이번 구현에 포함하지 않는다.
공식 파일 규격과 코드만 확인했고 국세청 시스템에서 합성 기부금을 발급하지 않았다.
