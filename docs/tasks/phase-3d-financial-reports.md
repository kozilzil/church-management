# Phase 3D: 월별 재정보고서

## 목표 및 완료 조건

- [x] 기간·기금 선택, 수입·지출·수지 차액과 기초·기말 자산 표시.
- [x] 월별·기금별·계정별 집계, 원장의 차변·대변과 대조.
- [x] 불변 원장만 집계하고 역분개 게시일·부분 월·윤년·마감 기간 처리.
- [x] 권한에 따른 상세 페이지 조회와 헌금/지출·사진/PDF 증빙 연결.
- [x] 조회·원장·원거래·내보내기 권한 분리 및 교회 경계 검증.
- [x] 화면에 표시된 원장 기준으로 집계 CSV 내보내기, 감사 및 최근 인증.
- [x] 큰 원화 합계의 정밀도와 조회 후 추가 게시에 대한 일관성 검증.

## 구현 및 검증

정책은 [ADR-010](../decisions/ADR-010-financial-reports.md)을 따른다.
API/실제 PostgreSQL 통합 테스트는 월별 수지·자산 변동, 기금, 역분개, 상세 페이지 합계, 큰 금액,
권한·교회·CSRF·최근 인증·MFA, 수식 주입 방지, 원거래·증빙과 미게시 제외를 검증한다.
화면 테스트는 보고서 전용 권한 진입, 표시 결과 기준 내보내기, 상세 페이지·증빙, 조회 실패 시 이전 결과 제거를 검증한다.
기존 전체 품질 검사와 독립 Compose 신규 설치·업그레이드·볼륨 보존·백업 복구 검증을 함께 실행한다.

운영자는 역할 관리에서 finance.report와 필요한 별도 상세·내보내기 권한을 부여한 뒤 재로그인한다.
재정 → 재정보고서 → 기간·기금 선택 → 보고서 조회 순서로 이용한다.

## 후속 개발

다음 단위는 회계연도별 계정·기금 예산 편성 및 원장 지출 대비 집행률이다.
결재 시 예산 부족 경고/차단 정책, 예산 변경 승인, 전용 XLSX/PDF 출력은 별도 목표로 구체화한다.
