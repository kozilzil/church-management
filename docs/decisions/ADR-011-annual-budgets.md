# ADR-011: 연간 예산 편성과 원장 집행률

- 상태: Accepted
- 날짜: 2026-09-21

## 업무 단위

교회·연도·지출 계정·기금별 연간 편성액을 관리한다. 첫 단계의 회계연도는 1월 1일~12월 31일이다.
일반 요구사항의 부서별 예산은 후속이며 기금이 부서와 동일하다고 가정하지 않는다.
지출 계정만 편성할 수 있다. 0원은 명시적 편성액이고, 이력이 없는 미편성과 구분한다.
한 항목 금액은 0–999999999999999원 정수 문자열이다. UI/API 집계 금액 역시 문자열이다.

budget.write 담당자가 사유를 입력하고 저장하면 즉시 현재 편성액이 된다. 별도의 초안·결재·확정 절차는 없다.
변경은 BudgetRevision을 추가하며 이전 금액·사유·작성자·시각을 보존한다. 금액 취소는 사유를 입력한 0원 변경으로 기록한다.
같은 금액의 재저장은 거부한다. 기존 버전을 보내는 낙관적 검사와 교회별 재정 잠금으로 동시 수정의 덮어쓰기를 막는다.
과거 연도나 마감된 원장 기간의 예산도 이력을 남겨 정정할 수 있다. 원장을 수정하거나 기간을 재개방하지 않는다.

## 계산

- 현재 예산: 조회 시점의 항목별 마지막 변경 금액.
- 집행액: 해당 연도에 게시된 지출 계정 차변 − 대변. 역분개는 역분개 게시 연도에 포함한다.
- 잔여액: 현재 예산 − 집행액. 미편성 항목은 잔여액 null.
- 집행률: 집행액 / 예산 × 100, 소수 둘째 자리 이하 버림(0 방향 절삭).
- 0원 또는 미편성 예산은 집행률 null. 음수 집행액·집행률은 역분개 등에 의해 허용한다.

전체 예산/집행 합계 외에 항목별 초과·미편성 건수를 표시한다. 다른 항목의 여유 예산으로 초과를 숨기지 않는다.
합계 집행액에는 미편성 지출도 포함한다. 순지출이 0이고 예산도 편성되지 않은 항목은 생략한다.
미지급 지출 요청·진행 중 결재는 포함하지 않는다. 예산 잔여액은 실제 현금 또는 지급 가능 잔액이 아니다.
회계 게시만 집계하므로 예산 저장 자체가 회계 분개를 만들지 않는다. 화면의 초과 표시는 결재/지급을 차단하지 않는다.
집계는 기존 재정 게시와 동일한 교회 잠금 안에서 실행한다. 읽은 뒤 새 거래가 게시되면 다시 조회하여 반영한다.
SQL numeric과 BigInt로 금액과 비율을 계산한다. 숫자 합산에 JS 부동소수점을 사용하지 않는다.

## 권한·무결성·배포

budget.read는 교회 전체 예산·집행 집계·변경 이력 열람이다. 교적/개인 지출/기존 재정보고서 권한과 별도로 부여한다.
budget.write와 budget.read를 모두 가진 담당자만 편성하며 최근 15분 인증, CSRF·Origin, 운영 MFA를 요구한다.
읽기 권한에는 원거래나 기부자·수령인 정보를 포함하지 않는다. 이력에 작성자 ID와 현재 계정 표시명을 반환한다.
조회·이력·저장은 감사하며 금액·사유·작성자 표시명을 감사 payload에 담지 않는다. 응답은 private, no-store다.

DB 복합 외래 키로 계정·기금·작성자의 교회 경계를 검사하고, 지출 계정 및 연속 변경 버전을 trigger로 검증한다.
기록 update/delete는 DB trigger로 거부하며 production runtime role에서도 해당 권한을 회수한다.
추가 runtime dependency나 서비스는 없다. migration과 기본 PostgreSQL 백업/복구 경로를 사용한다.

## 후속

사용자 정의 회계연도, 부서별 배정, 수입 예산, 결재 중 예약액, 변경 승인, 예산 초과 경고/지급 차단 정책,
예산 출력·내보내기는 별도 단위로 구체화한다.
