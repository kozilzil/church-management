# ADR-007: 요청자 지정 지출 결재선과 증빙·지급 원장

- 상태: Accepted
- 날짜: 2026-09-20

요청자가 개인별 순차 결재선을 정한다. 금액별 고정 결재선은 이번 요구사항에 적용하지 않는다.
상신 회차마다 금액·용도·수령인·계정·기금·증빙과 결재선을 보존한다.
요청자·승인자·지급자를 분리하고 수동 지급 기록과 회계 게시를 한 트랜잭션으로 처리한다.
게시 원장과 지급은 수정하지 않으며 열린 기간에 연결된 역분개를 만든다.

ARCHITECTURE.md의 S3 호환 인터페이스 방향은 유지하되 초기 단일 서버 배포에는
기존 uploads named volume을 사용하는 private storage adapter를 채택한다.
외부 스토리지 서비스를 필수로 추가하지 않고 기존 파일 백업/복구 계약을 활용한다.
공개 정적 파일 경로는 없으며 파일 조회마다 지출 권한을 검증한다.

권한 관리자는 finance.manage로 재정 역할을 만들어 다른 사용자에게 부여할 수 있으나
자기 역할 변경은 기존 정책대로 금지하며 재정 읽기/승인/지급 권한을 자동으로 얻지 않는다.
재정 설정·지급·역분개·마감은 로그인 후 15분 이내에 수행한다.
운영에서는 승인·지급·재정관리 권한 사용자도 MFA 확인 세션을 요구한다.
