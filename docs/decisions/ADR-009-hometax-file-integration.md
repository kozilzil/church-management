# ADR-009: 홈택스 전산매체 파일 연동

- 상태: Accepted
- 날짜: 2026-09-20

사용자는 홈택스 연동을 요청했다. 국세청의 공개 전산매체 제출요령과 기부금단체 매뉴얼을 확인했다.
확인 가능한 자동 발급 API 계약이 없으므로 A0420 파일 생성과 수동 결과 대조를 구현한다.
기관 로그인·인증서·실제 제출은 홈택스에서 수행하며 앱의 자체 발급번호와 혼동하지 않는다.

기부자/귀속연도별 최대 500건의 준비 스냅샷과 건별 결과 이력을 따로 저장한다. 원래
ReceiptClaim을 자체 영수증 또는 HometaxItem 중 하나만 참조하도록 확장하여 원장 역분개 보호와
서로 다른 채널의 중복 발급 방지에 같은 원칙을 적용한다. 준비 및 결과 이력은 수정/삭제하지 않는다.
결과 미확인 상태는 자동 해제하지 않으며, 담당자가 홈택스 미발급 또는 취소를 확인한 때만 claim을 해제한다.
국세청 매뉴얼은 중복 검증 없는 분할 발급과 부분 오류를 설명하므로 파일 생성 성공을 발급 완료로 취급하지 않는다.

식별번호는 기존 비저장 원칙을 유지한다. API는 비식별 제출 스냅샷을 권한·재인증·감사 검사 후 반환하고,
브라우저는 일회성 입력 번호와 결합하여 KSC-5601 파일을 만든다. API와 브라우저는 동일한 규격 serializer를
사용해 준비 전과 다운로드 시점에 형식 검사를 적용한다. 공통 runtime 모듈은 설치 시 빌드한다.
TextDecoder의 EUC-KR 매핑 중 KS X 1001 영역만 역매핑하며 인코딩 불가 문자를 대체하거나 절단하지 않는다.
추가 runtime dependency와 서비스는 필요하지 않다.

실제 발급 권한·로그인과 실제 기부 정보가 없는 상태에서는 홈택스 제출 성공까지 검증할 수 없다.
앱은 홈택스 조회로 검증했다고 표시하지 않으며 확인 참조/사유/담당자/시각을 수동 대조 증거로 남긴다.
