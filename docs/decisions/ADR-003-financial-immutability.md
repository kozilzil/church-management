# ADR-003: 게시된 재정 데이터 불변성

- 상태: Accepted
- 날짜: 2026-09-20

## Context

헌금과 회계 기록을 일반 CRUD 방식으로 수정·삭제하면 감사 추적과 결산 신뢰성이 무너진다.

## Decision

`POSTED` 상태의 헌금 배치와 분개는 update/delete하지 않는다. 오류는 원거래를 참조하는
reversal과 필요한 신규 거래로 정정한다. 모든 분개는 차변과 대변 합계가 일치해야 게시된다.

## Consequences

- 원장 이력이 보존되고 감사가 쉬워진다.
- UI에 수정 버튼 대신 정정 workflow가 필요하다.
- 잘못된 게시를 줄이기 위한 review 단계와 권한 분리가 필요하다.
