# ADR-008: 개별 헌금과 자체 기부금영수증

- 상태: Accepted
- 날짜: 2026-09-20

사용자는 개별 헌금 입력과 기부금영수증 발급을 요청했다. 기존 배치 중심 요구사항을 확장하여
개별 Offering을 검수/게시 단위로 삼는다. 배치 일괄 입력은 후속이며 단건 입력에 배치를 요구하지 않는다.
Finance 모듈 내부에서 헌금·원장·영수증 application service를 분리한다. 교적 연결에는 Registry의 공개
기부자 조회 서비스를 사용하고, 재정 담당자의 교적 전체 조회 권한을 요구하지 않는다.

Receipt 원본과 항목은 불변이다. 취소는 별도 기록하고 active claim만 해제하여 새 번호 재발급을 허용한다.
재출력은 원래 스냅샷과 번호를 유지한다. 유효 영수증이 참조하는 헌금의 역분개는 API와 DB에서 차단한다.
기존 원장 역분개 API로 헌금 정정 경로를 우회하지 못하게 한다.

주민등록번호 전체를 저장하는 필드는 추가하지 않는다. 출력 화면에서만 일회성 입력하며 서버에는 전송하지
않는다. 앱은 발급대장과 금액/항목/기관/기부자 스냅샷을 보존하고, 완성된 발급명세의 법정 보관은 교회가
별도로 수행한다. 이 제약은 초기 설정과 출력 화면에 명시한다. 현물/법인 발급/홈택스 전자발급은 지원 범위와
구분한다. 영수증 한 건(최대 500개 헌금)의 동기 발급을 먼저 구현하며 대량 일괄 발급은 비동기 후속 범위다.
